Como se usa

  1. Copia tokens.css al proyecto y enlazalo antes de tus estilos.
  2. Usa siempre las variables, nunca un HEX suelto en el codigo.
  3. Para modo oscuro basta con data-tema="oscuro" en el html.
  4. Si cambia un color de marca, edita el token y vuelve a generar el kit: los estados se recalculan solos.
